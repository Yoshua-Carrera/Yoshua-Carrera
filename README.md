# Hi, I'm Yoshua Carrera!

I'm a passionate learner with a knack for software development. Although I started as a front-end developer, I have a great interest in many different technologies, ranging from backend and DevOps to machine learning. My current interest revolves around software enablement through declarative systems, whether at the OS or program level. I am constantly trying to get into new niches and master different skillsets, which I intend to put together to increase the synergy of my workflow.
